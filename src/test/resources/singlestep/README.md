# SingleStepTests-format fixture

`3d.e.json` is a locally authored smoke-test vector using the state/memory JSON shape documented by [SingleStepTests/65816](https://github.com/SingleStepTests/65816). It is not copied from the upstream README or corpus. The test checks adapter initialization, one-instruction execution, and state comparison; it is not independent upstream differential validation or bus-cycle validation.

The upstream `SingleStepTests/65816` repository does not expose a license file, so this fixture is original and no upstream test vector is vendored.
